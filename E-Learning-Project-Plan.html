1 Executive Summary

This document presents a 7-day intensive sprint plan to build the MVP (Minimum Viable Product) of a multi-category E-Learning Platform serving Indian state-specific educational content across Web and Android platforms.

The platform covers 6 core educational modules — School Education (K-12), Competitive Exam Preparation, Higher Education (UG/PG), State & Central Government Jobs Preparation, and Teacher Certification — with integrated wallet-based payments, a digital e-book library, and a Binary MLM affiliate network.

⚠️ Important Timeline Note A 1-week timeline delivers a functional MVP with core user flows. A fully production-ready, polished product would realistically require 8–12 weeks with the same team. This plan assumes 6 dedicated full-time developers with zero context switching.

2 Project Overview

2.1 Purpose

Build a comprehensive mobile/web platform enabling users to register, browse state-specific educational content, purchase individual courses or e-books via an integrated wallet, and access multi-format learning materials (Videos, Notes, MCQs, Attachments, Lessons).

9 API Endpoints Summary

9.1 Authentication & Users (11 endpoints)

POST /api/auth/register — New user registration POST /api/auth/login — Login (UserID / Mobile / Name + Password) POST /api/auth/verify-otp — OTP verification POST /api/auth/refresh-token — JWT refresh POST /api/auth/forgot-password — Password reset initiation PUT /api/auth/reset-password — Password reset execution GET /api/users/profile — Get user profile PUT /api/users/profile — Update profile POST /api/users/kyc — Submit KYC documents GET /api/users/kyc/status — KYC verification status PUT /api/users/state — Update state preference

9.2 Content Hierarchy (10 endpoints)

GET /api/states — List all states GET /api/categories/:stateId — Categories by state GET /api/courses/:categoryId — Courses by category GET /api/subjects/:courseId — Subjects by course GET /api/chapters/:subjectId — Chapters by subject GET /api/assets/:chapterId — Assets by chapter GET /api/assets/:id/content — Specific asset content GET /api/mcq/:assetId — MCQ questions POST /api/mcq/:assetId/submit — Submit MCQ answers GET /api/search — Global content search

9.3 Wallet & Payments (6 endpoints)

GET /api/wallet/balance — Wallet balance POST /api/wallet/topup — Initiate top-up POST /api/wallet/topup/verify — Payment verification (webhook) GET /api/wallet/transactions — Transaction history POST /api/purchases/course — Purchase course POST /api/purchases/ebook — Purchase e-book

9.4 E-Book Library (4 endpoints)

GET /api/ebooks — Browse catalog GET /api/ebooks/:id — E-book detail GET /api/ebooks/my-library — User's purchased e-books GET /api/ebooks/:id/read — Open e-book reader

9.5 MLM / Affiliate (7 endpoints)

GET /api/mlm/referral-code — Get/generate referral code POST /api/mlm/join — Join via referral GET /api/mlm/tree — View binary tree (downline) GET /api/mlm/earnings — Earnings dashboard GET /api/mlm/team-stats — Team volume & stats POST /api/mlm/payout-request — Request payout GET /api/mlm/ranks — Rank progression
